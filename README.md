# ☕ Café com o Paulo

Um site moderno e responsivo desenvolvido para apresentar uma cafeteria fictícia chamada **Café com o Paulo**.  
O projeto foi criado utilizando HTML e CSS, com foco em experiência visual, apresentação de produtos e navegação intuitiva.

## 📸 Prévia do Projeto

O site possui:

- Página inicial com efeito visual moderno
- Seção sobre a cafeteria
- Catálogo de cafés
- Vídeo de fundo
- Localização integrada com Google Maps
- Botão de contato via WhatsApp
- Layout responsivo

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Maps Embed
- WhatsApp API
